## Deploy to GitHub Pages

1. Create a new public repository named `Srinath-Lottipalli-QA-Portfolio`.
2. Upload all files and folders from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

The resulting URL will normally be:

`https://YOUR-GITHUB-USERNAME.github.io/Srinath-Lottipalli-QA-Portfolio/`

If the GitHub username is `SrinathLottipalli`, the URL would be:

`https://SrinathLottipalli.github.io/Srinath-Lottipalli-QA-Portfolio/`
